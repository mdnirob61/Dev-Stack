## 📌 About The Project

**Dev Stack** is a beginner-friendly React project that allows users to
explore different technologies and create their own technology stack.

Users can select technologies, view their details, and manage their selected
stack easily.

---

## ✨ Features

| Feature | Description |
| --- | --- |
| 🔍 **Explore Technologies** | Browse technologies with their category, rating, difficulty, and description. |
| ➕ **Build Your Stack** | Add your favorite technologies to your personal stack. |
| 🗑️ **Manage Your Stack** | Remove individual technologies or remove all technologies at once. |

# ⚛️ React Questions & Answers

### 1. What is JSX, and why is it used in React?

**Ans:** JSX lets us write HTML-like code inside JavaScript. It makes React code easier to write.

### 2. What is the difference between props and state?

**Ans:** Props are data sent from parent to child. State is data that can change.

### 3. What does the `useState` hook do, and where did you use it?

**Ans:** `useState` stores data that can change. I used it to store the selected technologies.

### 4. What does the `useEffect` hook do?

**Ans:** `useEffect` runs code after a component renders. It is often used for loading data.

### 5. Why does every `.map()` item need a unique `key`?

**Ans:** A `key` helps React identify each item in a list.

### 6. What is conditional rendering?

**Ans:** It means showing different UI based on a condition. I used it to show the empty stack message.

### 7. How do parent and child components share data?

**Ans:** A parent sends data using props. A child can send changes back using a function received through props.
